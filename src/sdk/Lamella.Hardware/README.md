# Lamella.Hardware

`TargetBoard` answers which board a Lamella RHU program was built for: the name,
the maker, the product, the chip, the clock, the pins by the labels printed on the
board, and the buses with the rates the image serves; it also opens the standard
PWM channel and analog controller classes over the board's pins.
